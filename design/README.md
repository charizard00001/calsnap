# Snack Arcade — design source

The `.dc.html` files here are the artboards behind the published design
canvas (the Claude Design preview). They are the *source of truth for the
design*, not app code — nothing in `app/` or `components/` imports them.

The implementation lives in `components/ui/` (Sticker, StickerPressable,
Marquee, Icon, Snappy, Confetti, ArcadeBg, Chip) and `constants/theme.ts`.

Re-seeding the canvas: see the `/design` skill.
